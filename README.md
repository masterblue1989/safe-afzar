# سیف افزار (safe afzar) 🌿🛡️
### نرم‌افزار اندرویدی ذخیره اطلاعات هویتی و ۳ کد پستی با تم سبز پاستلی

این پروژه، نرم‌افزار نیتیو اندروید توسعه‌یافته با **Kotlin** و **Jetpack Compose (Material 3)** با نام تجاری **سیف افزار (safe afzar)** است.

---

## ✨ ویژگی‌های برجسته سیف افزار (safe afzar)

1. **پشتیبانی از ۳ کد پستی مجزا (منزل، محل کار، سایر/دلخواه):**
   - هر کد پستی به صورت ۱۰ رقمی با فرمت منظم (`12345 - 67890`) و دکمه کپی اختصاصی ذخیره می‌شود.

2. **ذخیره‌سازی اطلاعات فقط با ارقام استاندارد انگلیسی (0-9):**
   - هر شماره‌ای که با کیبورد فارسی یا عربی وارد شود، به صورت زنده و خودکار به ارقام انگلیسی تبدیل شده و در دیتابیس ذخیره می‌شود.

3. **دکمه‌های کپی سریع برای هر فیلد اطلاعاتی:**
   - با یک لمس، مقدار فیلد فوراً در حافظه موقت (Clipboard) کپی شده و فیدبک تصویری `✔ کپی شد!` نشان داده می‌شود.

4. **تم بسیار زیبا و ملایم سبز پاستلی:**
   - استفاده از طیف‌های سبز نعنایی ملایم (`#D8F2E3`، `#EBF7F0`، `#3B7E5F`).

5. **تمام متون ۱۰۰٪ فارسی و کاربرپسند.**

## 📦 نحوه دریافت و تولید فایل APK جهت نصب

برای ساخت فایل خروجی `.apk` که مستقیماً روی گوشی نصب شود، ۲ راهکار بسیار ساده وجود دارد:

### روش اول: تولید خروجی با Android Studio (پیشنهادی و استاندارد)
1. برنامه **Android Studio** را در کامپیوتر خود باز کنید.
2. گزینه **Open** را زده و پوشه `d:\first app` را انتخاب کنید.
3. از منوی بالای نرم‌افزار، به مسیر زیر بروید:
   ```
   Build  >  Build Bundle(s) / APK(s)  >  Build APK(s)
   ```
4. پس از چند ثانیه، پیام `APK(s) generated successfully` نمایش داده می‌شود و با کلیک روی گزینه **locate**، فایل آماده نصب به نام `app-debug.apk` در اختیار شما قرار می‌گیرد:
   ```
   d:\first app\app\build\outputs\apk\debug\app-debug.apk
   ```
5. این فایل را با کابل، تلگرام یا فلش به گوشی اندرویدی خود منتقل کرده و نصب نمایید.

---

### روش دوم: ساخت خودکار در کلود (GitHub Actions)
فایل آماده گردش کار کلود در مسیر زیر قرار داده شده است:
```
d:\first app\.github\workflows\build-apk.yml
```
با آپلود این پروژه در هر مخزن گیت‌هاب، گیت‌هاب به صورت خودکار پروژه را کامپایل کرده و فایل دانلودی `safe-afzar-debug.apk` را برای دانلود آماده می‌کند.

---

### روش سوم: نصب فوری روی گوشی بدون نیاز به ساخت APK (PWA)
فایل [**`d:\first app\interactive_preview.html`**](file:///d:/first%20app/interactive_preview.html) مجهز به `manifest.json` استاندارد است. با باز کردن این صفحه در مرورگر Chrome گوشی و انتخاب گزینه:
> **افزودن به صفحه اصلی (Add to Home screen / Install app)**

نرم‌افزار دقیقاً همانند یک اپلیکیشن مستقل با آیکون **safe afzar** روی گوشی شما نصب شده و کاملاً آفلاین کار می‌کند!
